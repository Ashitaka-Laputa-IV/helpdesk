# RRF 参数调优报告

## 1. 目的

新版 `rag_router_rrf.py` 用 RRF 替代 reranker，但初版参数是照搬重排版的
（`bm25_k=10 / sem_k=15 / rrf_k=60 / top_n=5`）。两条链路的代价结构不同，
参数不应相同。本报告扫描参数空间，给出各自的最优配置。

## 2. 方法

脚本：`tests/sweep_fusion.py`

```bash
uv run python tests/sweep_fusion.py --tier paraphrase
uv run python tests/sweep_fusion.py --tier title
```

- 每条查询只做**一次召回**（bm25 取 30、向量取 30），各种截断/融合配置**离线计算**；
- rerank 排名与 `top_n` 无关，因此每个候选池只重排一次，再按 `top_n` 切片；
- 指标：`Recall@top_n`、`MRR`（正解首次出现名次的倒数均值）。

扫描维度：

| 参数 | 取值 | 说明 |
|---|---|---|
| `bm25_k` | 10, 20 | bm25 召回深度 |
| `sem_k` | 15, 25 | 向量召回深度 |
| `rrf_k` | 20, 60 | RRF 平滑常数（60 是业界常用值） |
| `top_n` | 5, 8, 10 | 进入上下文的条数 |

## 3. 结果

### 3.3 标题档（简单档）

| 方案 | 最优配置 | Recall | MRR |
|---|---|---|---|
| RRF | bm25_k=10, sem_k=15, rrf_k=60 | 96.7% | 0.786 |
| rerank | bm25_k=10, sem_k=25, top_n≥5 | **100%** | **0.925** |

简单档下 rerank 仍有优势，但两者都接近上限，区分度不高。

### 3.4 运行一致性

改写档跑两遍，Recall / MRR **完全一致**（确定性指标）。
rerank 耗时第二遍为 816ms / 1055ms（首轮 788ms / 1007ms），波动约 4%。

## 4. 结论

1. **`rrf_k` 用 20 优于 60**：同等条件下 MRR 0.687 → **0.721**（+0.034）。
   常用值 60 偏向"深度共识"，小语料下反而钝化了两路的分差。
2. **RRF 适合更深的 bm25 召回**：`bm25_k` 10 → 20 → 25，top-5 召回 86.7% → 90.0% → 90.0%，
   MRR 0.705 → 0.721 → **0.723**，收益边际递减但方向一致。
   RRF 只看名次，多召回不引入分数噪声，几乎无成本（bm25 每次 0.5ms）。
3. **向量召回不宜加深**：`sem_k` 25 反而使 MRR 从 0.721 掉到 0.691——多出来的候选拉低了融合排序质量。
4. **`top_n` 8 是平衡点**：最佳配置下 5 也能到 90%，但换个配置（如 sem_k=25）只有 83~87%；
   8 更稳，且对生成上下文长度影响可接受。
5. **rerank 需 `top_n=10` 才追回召回**：93.3% vs RRF 90.0%（+3.3 个百分点），
   但 MRR 反而更低（0.713 vs 0.721），代价是 542ms 对约 15ms。

## 5. 已应用的改动

| 文件 | 参数 | 原值 | 新值 |
|---|---|---|---|
| `rag_router_rrf.py` | `BM25_K` | 10 | **25** |
| `rag_router_rrf.py` | `SEMANTIC_K` | 复用 rag_router_rerank | **15（独立定义）** |
| `rag_router_rrf.py` | `RRF_K` | 60 | **20** |
| `rag_router_rrf.py` | `TOP_N` | 5 | **8** |
| `rag_router_rerank.py` | `TOP_K` | 5 | **8** |

`SEMANTIC_K` 定为 15（扫描显示加深到 25 会拉低 MRR）。

## 6. 推荐用法

| 场景 | 配置 | 依据 |
|---|---|---|
| 默认 / 延迟敏感 | RRF：bm25_k=25, sem_k=15, rrf_k=20, top_n=8 | 90% 召回、MRR 0.723、约 15ms |
| 追召回、可接受 500ms | rerank：bm25_k=10, sem_k=15, top_n=10 | 93.3% 召回，但是 MRR 略低 |

## 7. 局限

- 评测集 30 条，±3 个百分点噪声；结论看趋势，不宜纠结单点。
- 正解按「文档」判定，同一文档内选哪个分块不影响得分。
- 复杂/多跳问题未覆盖，当前结论只适用于单跳事实型提问。
- rerank 耗时受本地服务抖动影响，绝对值仅供量级参考。
